# Pharmacy App - Lab 1 (Web Development and Web Design)

## Опис проекту
Створено базовий статичний веб-сайт для сервісу аптеки.  
Функціонал реалізований у вигляді окремих сторінок:
- Сторінка входу (Login)
- Сторінка виходу (Logout)
- Список препаратів
- Додавання препарату
- Редагування препарату
- Перегляд інформації про препарат
- Відображення помилок (Error Page)

## Технології
- HTML5
- SASS (SCSS синтаксис)
- Компільований CSS
- Git + GitHub
- GitHub Pages для розгортання

## Особливості
- Використана адаптивна верстка
- Застосовані змінні для кольорів через SCSS
- Створено простий міксин для стилізації кнопок
- Організована структура проекту відповідно до вимог
- Забезпечено правильну структуру HTML-документів згідно стандартів

## Як запустити
1. Відкрити файл `index.html` у браузері локально, або
2. Перейти на [GitHub Pages за цим посиланням](https://github.com/VolodymyrMolnar/web).
